Suport de lecție – Funcția radical

Definiție: Se numește funcție radical (de ordin n∈N∗n \in \mathbb{N}^*n∈N∗, n≥2n \ge 2n≥2) funcția f:D→Df : D \to Df:D→D, definită prin:

f(x)=xnf(x) = \sqrt[n]{x}f(x)=nx​

unde domeniul (și codomeniul) DDD este:

  • D=[0,+∞)D = [0, +\infty)D=[0,+∞), dacă nnn este număr par (n=2kn = 2kn=2k, k∈N∗k \in \mathbb{N}^*k∈N∗);
  • D=RD = \mathbb{R}D=R, dacă nnn este număr impar (n=2k+1n = 2k + 1n=2k+1, k∈N∗k \in \mathbb{N}^*k∈N∗).

Deoarece definiția depinde de paritatea ordinului nnn, distingem două cazuri:

Cazul I: nnn este număr par (n=2kn = 2kn=2k, cu k∈N∗k \in \mathbb{N}^*k∈N∗)

Funcția f:[0,+∞)→[0,+∞)f : [0, +\infty) \to [0, +\infty)f:[0,+∞)→[0,+∞), f(x)=x2kf(x) = \sqrt[2k]{x}f(x)=2kx​, este inversa funcției bijective:

(Exemple: f(x)=xf(x) = \sqrt{x}f(x)=x​, f(x)=x4f(x) = \sqrt[4]{x}f(x)=4x​, f(x)=x6f(x) = \sqrt[6]{x}f(x)=6x​.)

1. Trasarea graficului (prin simetrie)

  • Graficul unei funcții bijective și graficul inversei sale sunt simetrice față de prima bisectoare (dreapta y=xy = xy=x).
