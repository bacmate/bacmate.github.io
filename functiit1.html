Funcții – Noțiuni fundamentale

1. Introducere și motivație practică

Ideea de funcție s-a desprins din practică, unde întâlnim adesea situații în care valorile unei mărimi depind de valorile altei mărimi:

  • Prețul unei curse cu taxiul depinde de distanța parcursă (pretul este o functie de distanta parcursa).

  • Aria unui teren de formă pătrată depinde de lungimea laturii sale.

  • Temperatura într-o localitate depinde de momentul de timp (ex.: la ora 12→10∘C12 \to 10^\circ\text{C}12→10∘C).

În alte situații, fiecărui element dintr-o mulțime îi asociem, după o regulă, un singur element dintr-o altă mulțime:

  • elevundefinedasociemdata nașterii\text{elev} \xrightarrow{\text{asociem}} \text{data nașterii}elevasociem​data nașterii

  • persoana˘⟶vaˆrsta\text{persoană} \longrightarrow \text{vârsta}persoana˘⟶vaˆrsta

  • carte⟶numa˘rul de pagini\text{carte} \longrightarrow \text{numărul de pagini}carte⟶numa˘rul de pagini

2. Definiția funcției și elemente componente

O funcție este definită de 3 elemente, formând tripletul (A,B,f)(A, B, f)(A,B,f):

  1. O mulțime nevidă A≠∅A \neq \emptysetA=∅, numită domeniul de definiție.

  2. O mulțime nevidă B≠∅B \neq \emptysetB=∅, numită codomeniu.

  3. Legea de corespondență (notată fff) - o regulă prin care fiecărui element x∈Ax \in Ax∈A i se asociază un singur element y=f(x)∈By=f(x)\in By=f(x)∈B.

Notații și terminologie:

  • Funcția se notează: f:A→Bf: A \to Bf:A→B.

  • Dacă f(x)=yf(x) = yf(x)=y, atunci:

    • elementul yyy se numește valoarea funcției fff în elementul xxx sau imaginea lui xxx prin fff;

    • elementul xxx se numește o preimagine a lui yyy prin fff (spunem „o preimagine”, și nu „preimaginea”, deoarece un element yyy poate avea mai multe preimagini - poate “proveni” din mai multe elemente xxx din domeniu).

Metafora: Funcția „mașină” Putem privi o funcție ca pe un mecanism (o „mașină”) în care introducem o valoare xxx (din domeniu), mecanismul aplică regula de calcul, iar la “ieșire” obținem o singură valoare y=f(x)y = f(x)y=f(x) din codomeniu.

3. Moduri de a descrie o funcție

I. Sintetic (atunci când domeniul este o mulțime finită)

Pentru fiecare element x∈Ax \in Ax∈A se precizează valoarea f(x)f(x)f(x).

  1. Prin tabel de valori

  2. Prin diagrame cu săgeți (diagrame Venn)

II. Analitic (printr-o formulă)

Legea de corespondență este dată printr-o expresie matematică.
Exemplu: f:R→Rf: \mathbb{R} \to \mathbb{R}f:R→R, f(x)=2x−1f(x) = 2x - 1f(x)=2x−1 (funcție de gradul întâi).

  • Calculul unor valori: f(0)=2⋅0−1=−1f(0) = 2 \cdot 0 - 1 = -1f(0)=2⋅0−1=−1; f(1)=2⋅1−1=1\quad f(1) = 2 \cdot 1 - 1 = 1f(1)=2⋅1−1=1.

4. Funcții egale

Fie funcțiile f:A→Bf: A \to Bf:A→B și g:C→Dg: C \to Dg:C→D. Spunem că funcțiile fff și ggg sunt egale (f=gf = gf=g) dacă au același domeniu, același codomeniu și aceeași lege de corespondență:

f=g  ⟺  def{A=CB=Df(x)=g(x), ∀x∈Af = g \stackrel{\text{def}}{\iff} \begin{cases} A = C \\ B = D \\ f(x) = g(x), \ \forall x \in A \end{cases}f=g⟺def​⎩⎨⎧​A=CB=Df(x)=g(x), ∀x∈A​

Exemple:

  1. Fie f,g:{−1,0,1}→Rf, g: \{-1, 0, 1\} \to \mathbb{R}f,g:{−1,0,1}→R, definite prin f(x)=x2f(x) = x^2f(x)=x2 și g(x)=x4g(x) = x^4g(x)=x4.

    • Domeniile și codomeniile coincid.

    • Verificăm valorile: f(−1)=g(−1)=1f(-1) = g(-1) = 1f(−1)=g(−1)=1;  f(0)=g(0)=0\ f(0) = g(0) = 0 f(0)=g(0)=0;  f(1)=g(1)=1\ f(1) = g(1) = 1 f(1)=g(1)=1.

    • Concluzie: f=gf = gf=g.

  2. Fie f,g:R→Rf, g: \mathbb{R} \to \mathbb{R}f,g:R→R, definite prin f(x)=x2+3x+2f(x) = x^2 + 3x + 2f(x)=x2+3x+2 și g(x)=(x+1)(x+2)g(x) = (x + 1)(x + 2)g(x)=(x+1)(x+2).

    • Prin desfacerea parantezelor obținem g(x)=x2+3x+2=f(x)g(x) = x^2 + 3x + 2 = f(x)g(x)=x2+3x+2=f(x), ∀x∈R\forall x \in \mathbb{R}∀x∈R, deci f=gf = gf=g.

5. Restricții ale unei funcții

(Se restrânge domeniul de definiție, dar se păstrează codomeniul și legea de corespondență).

Definiție: Fie f:A→Bf: A \to Bf:A→B și o submulțime nevidă M⊆AM \subseteq AM⊆A (M≠∅M \neq \emptysetM=∅). Funcția g:M→Bg: M \to Bg:M→B, definită prin g(x)=f(x)g(x) = f(x)g(x)=f(x), ∀x∈M\forall x \in M∀x∈M, se numește restricția funcției fff la mulțimea MMM și se notează g=f∣Mg = f\vert{}_Mg=f∣M​ (sau fMf_MfM​).

Exemplu: Fie f:R→Rf: \mathbb{R} \to \mathbb{R}f:R→R, f(x)=2x+1f(x) = 2x + 1f(x)=2x+1 și g:(0,∞)→Rg: (0, \infty) \to \mathbb{R}g:(0,∞)→R, g(x)=2x+1g(x) = 2x + 1g(x)=2x+1. Funcția ggg este restricția lui fff la intervalul (0,∞)(0, \infty)(0,∞) (g=f∣(0,∞)g = f\vert{}_{(0, \infty)}g=f∣(0,∞)​).

6. Imaginea unei funcții

Definiție: Fie f:A→Bf: A \to Bf:A→B. Se numește imaginea funcției fff (notată Im f\text{Im } fIm f sau f(A)f(A)f(A)) mulțimea tuturor valorilor funcției:

Im f={f(x)∣x∈A}\text{Im } f = \{ f(x) \mid x \in A \}Im f={f(x)∣x∈A}

Exemplu introductiv: Fie f:{0,1,2}→Rf: \{0, 1, 2\} \to \mathbb{R}f:{0,1,2}→R, f(x)=2x+1f(x) = 2x + 1f(x)=2x+1.

  • a) Calculăm valorile funcției: f(0)=1f(0) = 1f(0)=1,  f(1)=3\ f(1) = 3 f(1)=3,  f(2)=5\ f(2) = 5 f(2)=5.

  • b) Im f={1,3,5}\text{Im } f = \{1, 3, 5\}Im f={1,3,5}.

Caracterizarea prin ecuația f(x)=yf(x) = yf(x)=y:
Un element y∈By \in By∈B aparține imaginii funcției dacă și numai dacă ecuația f(x)=yf(x) = yf(x)=y are cel puțin o soluție x∈Ax \in Ax∈A:

Im f={y∈B∣∃x∈A astfel ıˆncaˆt f(x)=y}\text{Im } f = \{ y \in B \mid \exists x \in A \text{ astfel încât } f(x) = y \}Im f={y∈B∣∃x∈A astfel ıˆncaˆt f(x)=y}

RETINE: Un element yyy din codomeniu apartine imaginii funcției dacă și numai dacă are cel putin o preimagine în domeniu.

Algoritm practic pentru determinarea imaginii unei funcții (Im f\text{Im } fIm f)

Pentru a afla imaginea unei funcții de la un domeniu AAA la codomeniul BBB, parcurgem urmatorii pasi:

  1. Se consideră ecuația f(x)=yf(x) = yf(x)=y, unde yyy este un element oarecare din codomeniu.

  2. Se rezolvă ecuația, exprimându-l pe xxx în funcție de yyy.

  3. Se pune condiția ca valoarea lui xxx obținută să aparțină domeniului de definiție AAA (x∈Ax \in Ax∈A). Mulțimea valorilor lui yyy pentru care această condiție este îndeplinită reprezintă exact Im f\text{Im } fIm f!
