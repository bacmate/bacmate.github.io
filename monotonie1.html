I. Proprietăți privind operațiile cu funcții monotone

Fie I⊆RI \subseteq \mathbb{R}I⊆R un interval și f,g:I→Rf, g: I \to \mathbb{R}f,g:I→R două funcții.

1. Adunarea cu o constantă

Fie c∈Rc \in \mathbb{R}c∈R o constantă reală.

  • Proprietate: Adunarea cu o constantă păstrează tipul de monotonie.

    • Dacă fff este crescătoare (respectiv descrescătoare), atunci f+cf + cf+c este crescătoare (respectiv descrescătoare).

2. Suma a două funcții monotone

  • Dacă fff și ggg sunt crescătoare, atunci suma f+gf + gf+g este crescătoare.

  • Dacă fff și ggg sunt descrescătoare, atunci suma f+gf + gf+g este descrescătoare.

  • ATENTIE! Daca fff este crescatoare iar ggg descrescatoare, nu putem spune nimic despre monotonia sumei, in cazul general!!!

3. Înmulțirea cu o constantă

Fie c∈R∗c \in \mathbb{R}^*c∈R∗ o constantă reală nenulă.

  • Constantă pozitivă (c>0c > 0c>0): Atunci functia cfcfcf are aceeasi monotonie ca fff.

  • Constantă negativă (c<0c < 0c<0):

  • In acest caz cfcfcf are monotonie diferita fata de fff:

    • fff crescătoare   ⟹  c⋅f\implies c \cdot f⟹c⋅f descrescătoare.

    • fff descrescătoare   ⟹  c⋅f\implies c \cdot f⟹c⋅f crescătoare.

4. Inversa 1/f1/f1/f

Fie f:I→(0,∞)f: I \to (0,\infty)f:I→(0,∞) o funcție cu valori strict pozitive (esential!).

  • Dacă fff este crescătoare , atunci 1f\frac{1}{f}f1​ este descrescătoare.

  • Dacă fff este descrescătoare , atunci 1f\frac{1}{f}f1​ este crescătoare.

5. Ridicarea la putere (fnf^nfn)

Fie n∈N∗n \in \mathbb{N}^*n∈N∗.

  • Putere pară (n=2kn=2kn=2k par):

    • Dacă fff este crescătoare și pozitiva (f(x)≥0f(x) \ge 0f(x)≥0), atunci f2kf^{2k}f2k este crescătoare .

    • Dacă fff este descrescătoare și pozitiva (f(x)≥0f(x) \ge 0f(x)≥0), atunci f2kf^{2k}f2k este descrescătoare.

  • Putere impară (n=2k+1n=2k+1n=2k+1 impar):

    • Ridicarea la o putere impară păstrează întotdeauna tipul de monotonie (fără a fi necesară condiția de pozitivitate).

    • Dacă fff este crescătoare, atunci f2k+1f^{2k+1}f2k+1 este crescătoare.

    • Dacă fff este descrescătoare, atunci f2k+1f^{2k+1}f2k+1 este descrescătoare.

6. Produsul a două funcții monotone

Fie f,g:I→(0,+∞)f, g: I \to (0, +\infty)f,g:I→(0,+∞) două funcții cu valori strict pozitive.

  • Dacă fff și ggg sunt crescătoare, atunci functia f⋅gf \cdot gf⋅g este crescătoare.

  • Dacă fff și ggg sunt descrescătoare, atunci functia f⋅gf \cdot gf⋅g este descrescătoare.

7. Compunerea funcțiilor monotone

Fie f:I→Jf: I \to Jf:I→J și g:J→Rg: J \to \mathbb{R}g:J→R.

  • Monotonii de același fel   ⟹  \implies⟹ rezultat crescător: Dacă fff și ggg au același tip de monotonie, (g∘f)(g \circ f)(g∘f) este crescătoare.

  • Monotonii diferite   ⟹  \implies⟹ rezultat descrescător: Dacă fff și ggg au monotonii diferite, (g∘f)(g \circ f)(g∘f) este descrescătoare.
