1. Definiția logaritmului

Fie a>0,a≠1a > 0, a \neq 1a>0,a=1 și b>0b > 0b>0. Numărul c se numește logaritmul numărului bbb în baza aaa dacă ac=ba^c = bac=b.

log⁡ab=c  ⟺  ac=b\log_a b = c \iff a^c = bloga​b=c⟺ac=b

  • Condiții de existență (C.E.): Baza trebuie să fie strict pozitivă și diferită de 111 (a>0,a≠1a > 0, a \neq 1a>0,a=1), iar argumentul trebuie să fie strict pozitiv (b>0b > 0b>0).

2. Valori fundamentale

  • log⁡a1=0\log_a 1 = 0loga​1=0 (deoarece a0=1a^0 = 1a0=1)

  • log⁡aa=1\log_a a = 1loga​a=1 (deoarece a1=aa^1 = aa1=a)

  • log⁡a(an)=n\log_a (a^n) = nloga​(an)=n

3. Proprietăți operatorii (Reguli de calcul)

Dacă x>0x > 0x>0 și y>0y > 0y>0, atunci:

  • Logaritmul unui produs=suma logaritmilor: log⁡a(x⋅y)=log⁡ax+log⁡ay\log_a (x \cdot y) = \log_a x + \log_a yloga​(x⋅y)=loga​x+loga​y

  • Logaritmul unei fractii=diferenta logaritmilor log⁡a(xy)=log⁡ax−log⁡ay\log_a \left(\frac{x}{y}\right) = \log_a x - \log_a yloga​(yx​)=loga​x−loga​y

  • Logaritmul unei puteri log⁡a(xn)=n⋅log⁡ax\log_a (x^n) = n \cdot \log_a xloga​(xn)=n⋅loga​x

4. Logaritmi zecimali și Schimbarea bazei

  • Logaritmul zecimal: Notat cu lg⁡x\lg xlgx, reprezintă logaritmul în baza 101010 (lg⁡x=log⁡10x\lg x = \log_{10} xlgx=log10​x). Prin convenție, baza 101010 nu se mai scrie.

  • Formula de schimbare a bazei:

    log⁡ab=log⁡cblog⁡ca(unde c>0,c≠1)\log_a b = \frac{\log_c b}{\log_c a} \quad (\text{unde } c > 0, c \neq 1)loga​b=logc​alogc​b​(unde c>0,c=1)

    • Caz particular util: log⁡ab=1log⁡ba\log_a b = \frac{1}{\log_b a}loga​b=logb​a1​

14. Calculul pH-ului (Chimie): În chimie, gradul de aciditate al unei soluții (pH-ul) se calculează cu ajutorul logaritmului zecimal, folosind formula:

pH=−lg⁡[H+]\text{pH} = -\lg[H^+]pH=−lg[H+]

unde [H+][H^+][H+] reprezintă concentrația ionilor de hidrogen (exprimată în moli/litru).

  • a) Calculați pH-ul unei ape potabile știind că concentrația ionilor de hidrogen este [H+]=10−7 mol/l[H^+] = 10^{-7} \text{ mol/l}[H+]=10−7 mol/l.

  • b) Oțetul comercial are o concentrație a ionilor de hidrogen [H+]=10−3 mol/l[H^+] = 10^{-3} \text{ mol/l}[H+]=10−3 mol/l, iar sucul de lămâie [H+]=10−2 mol/l[H^+] = 10^{-2} \text{ mol/l}[H+]=10−2 mol/l. Calculați pH-ul ambelor produse și stabiliți care dintre ele este mai acid.
