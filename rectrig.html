2. Formular Trigonometric

Relații fundamentale:

  • sin⁡2x+cos⁡2x=1\sin^2 x + \cos^2 x = 1sin2x+cos2x=1

  • tg x=sin⁡xcos⁡x,ctg x=cos⁡xsin⁡x,tg x⋅ctg x=1\text{tg } x = \frac{\sin x}{\cos x}, \quad \text{ctg } x = \frac{\cos x}{\sin x}, \quad \text{tg } x \cdot \text{ctg } x = 1tg x=cosxsinx​,ctg x=sinxcosx​,tg x⋅ctg x=1

Suma și diferența de unghiuri:

  • sin⁡(a±b)=sin⁡acos⁡b±sin⁡bcos⁡a\sin(a \pm b) = \sin a \cos b \pm \sin b \cos asin(a±b)=sinacosb±sinbcosa

  • cos⁡(a±b)=cos⁡acos⁡b∓sin⁡asin⁡b\cos(a \pm b) = \cos a \cos b \mp \sin a \sin bcos(a±b)=cosacosb∓sinasinb

  • tg (a±b)=tg a±tg b1∓tg a⋅tg b\text{tg }(a \pm b) = \frac{\text{tg } a \pm \text{tg } b}{1 \mp \text{tg } a \cdot \text{tg } b}tg (a±b)=1∓tg a⋅tg btg a±tg b​

Unghi dublu și jumătate:

  • sin⁡(2a)=2sin⁡acos⁡a\sin(2a) = 2\sin a \cos asin(2a)=2sinacosa

  • cos⁡(2a)=cos⁡2a−sin⁡2a=2cos⁡2a−1=1−2sin⁡2a\cos(2a) = \cos^2 a - \sin^2 a = 2\cos^2 a - 1 = 1 - 2\sin^2 acos(2a)=cos2a−sin2a=2cos2a−1=1−2sin2a

  • sin⁡2(a2)=1−cos⁡a2,cos⁡2(a2)=1+cos⁡a2\sin^2\left(\frac{a}{2}\right) = \frac{1 - \cos a}{2}, \quad \cos^2\left(\frac{a}{2}\right) = \frac{1 + \cos a}{2}sin2(2a​)=21−cosa​,cos2(2a​)=21+cosa​

Transformarea sumelor în produse:

  • sin⁡p+sin⁡q=2sin⁡(p+q2)cos⁡(p−q2)\sin p + \sin q = 2\sin\left(\frac{p+q}{2}\right)\cos\left(\frac{p-q}{2}\right)sinp+sinq=2sin(2p+q​)cos(2p−q​)

  • sin⁡p−sin⁡q=2sin⁡(p−q2)cos⁡(p+q2)\sin p - \sin q = 2\sin\left(\frac{p-q}{2}\right)\cos\left(\frac{p+q}{2}\right)sinp−sinq=2sin(2p−q​)cos(2p+q​)

  • cos⁡p+cos⁡q=2cos⁡(p+q2)cos⁡(p−q2)\cos p + \cos q = 2\cos\left(\frac{p+q}{2}\right)\cos\left(\frac{p-q}{2}\right)cosp+cosq=2cos(2p+q​)cos(2p−q​)

  • cos⁡p−cos⁡q=−2sin⁡(p+q2)sin⁡(p−q2)\cos p - \cos q = -2\sin\left(\frac{p+q}{2}\right)\sin\left(\frac{p-q}{2}\right)cosp−cosq=−2sin(2p+q​)sin(2p−q​)

Aplicații în geometrie (Triunghi oarecare):
