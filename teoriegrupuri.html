Suport Teoretic: Introducere în Teoria Grupurilor (Clasa a XII-a, Mate-Info) —

1. Ce este o structură algebrică?

O structură algebrică este formata dintr-o mulțime nevidă înzestrată cu una sau mai multe legi de compoziție care îndeplinesc anumite proprietăți, numite axiomele structurii.

Structurile algebrice pe care le vom intalni sunt: monoid, grup, inel și corp.

2. Noțiunea de Monoid

  • Definiție: Fie MMM o mulțime nevidă și * o lege de compoziție internă pe M.M.M. Perechea (M,∗)(M, *)(M,∗) se numește monoid dacă:

    1. Legea * este asociativă: (x∗y)∗z=x∗(y∗z)(x * y) * z = x * (y * z)(x∗y)∗z=x∗(y∗z), ∀x,y,z∈M\forall x, y, z \in M∀x,y,z∈M.

    2. Legea * admite element neutru în MMM: ∃e∈M\exists e \in M∃e∈M astfel încât x∗e=e∗x=xx * e = e * x = xx∗e=e∗x=x, ∀x∈M\forall x \in M∀x∈M.

3. Definiția Grupului

Un grup este un monoid in care fiecare element este simetrizabil in raport cu legea.

  • Definiție: Fie GGG o mulțime nevidă și * o lege de compoziție pe GGG.
    Perechea ordonată (G,∗)(G, *)(G,∗) se numește grup dacă :

    1. Legea * este asociativă.

    2. Legea * admite element neutru.

    3. Orice element din GGG este simetrizabil in raport cu legea *.

Observație: Dacă in plus legea este și comutativă (x∗y=y∗xx * y = y * xx∗y=y∗x, ∀x,y∈G\forall x, y \in G∀x,y∈G), grupul se numește grup comutativ sau abelian.

5. Contraexemple (Structuri care NU sunt grupuri)

  • (N,+)(\mathbb{N}, +)(N,+) nu este grup. Adunarea este asociativă și are element neutru (000), dar elementele nenule nu au simetrice (opuse) în N\mathbb{N}N (de exemplu, opusul lui 222 este −2∉N-2 \notin \mathbb{N}−2∈/N). Este doar monoid.

  • (Z,⋅)(\mathbb{Z}, \cdot)(Z,⋅) — Nu este grup: Înmulțirea este asociativă și are element neutru (111), însă nu toate elementele sunt inversabile (de exemplu, elementul 222 nu are invers pentru ca 12∉Z\frac{1}{2} \notin \mathbb{Z}21​∈/Z). Este tot monoid.
